========================

  - title

  - cost (optional for profit)

  - status (AVAILABLE, PENDING, SOLD, ARCHIVED)

  - photos (multi upload)

  - last contacted date

  - payment type (Cash, CashApp, Zelle, etc.)
  - meetup spot label
  - date/time
  - notes
- Dashboard stats:
  - revenue last 7/30 days
  - profit estimate (sale - cost)
  - days-to-sell averages by category/powerType
  - inventory counts by status

5) Follow-ups + Retention
- Follow-up types: new inventory drop, back in stock, meetup reminder, check-in
- Templates that produce SMS-style text
- “Copy message” button (I paste into phone)
- Suggested follow-ups:
  - If buyer bought GAS -> suggest when a GAS listing is added
  - If buyer bought 40V -> suggest when a 40V listing is added
  - Repeat buyers -> monthly check-in suggestion

- Only show listings where:
  - isPublished = true
  - status = AVAILABLE
